# Netflix Clone

A full-stack Netflix clone built with React and Node.js.

## Project Structure

```
Netflix_clone/
├── frontend/          # React frontend application
│   ├── src/          # Source files
│   ├── public/       # Static assets
│   └── package.json  # Frontend dependencies
│
└── backend/          # Node.js backend API
    ├── models/       # Database models
    ├── routes/       # API routes
    └── server.js     # Server entry point
```

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm start
```

## Technologies Used

### Frontend
- React + Vite
- React Router
- TMDB API

### Backend
- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication
